# Moovit vs. BusLive – feature research (Nov 2026)

Sources: Moovit's own pages and press releases (navigation guide, "Moovit Assistant" press release May 2026),
Google Play listing summaries, third-party guides. Only features, not Moovit's design or branding, are copied.

| Moovit feature | BusLive | Notes |
|---|---|---|
| "Where to?" search on home + one-tap Home / Work / saved places | ✅ | Quick-place chips on the home map |
| Search lines / stations / places | ✅ | One unified box |
| Live arrivals from vehicle GPS | ✅ | SIRI via Stride, labeled "LIVE · estimate" + age |
| Live vehicles on a line's map | ✅ | Line screen + "Show line" |
| Station screen: lines + next arrivals | ✅ | Stop sheet / screen |
| Trip options with total time, arrival, transfers, walking | ✅ | + wait, ride, stops |
| **Trip Insights** labels (Earliest arrival, Fewest transfers, Least walking, Direct, Tight transfer, Long wait, Last departure) | ✅ | Computed on the phone, free |
| **Smart filters / sorting** (fastest, fewest transfers, least walking, leave latest) | ✅ | Free (Moovit puts advanced ones behind Moovit+) |
| Depart at / **Arrive by** | ✅ | |
| **Optimal departure time** ("leave in X min") | ✅ | |
| Live directions, step by step | ✅ | Foreground service, works locked |
| **Get-off alerts** (2 stops before, get off now) | ✅ | Vibration + notification |
| **Disruption detection + trip recovery** (missed bus → reroute) | ✅ | Detects the bus already left your stop; one-tap re-plan from where you are |
| Share trip / ETA | ✅ | |
| Favorites (lines, stops, places) + widget | ✅ | |
| Arrival reminders | ✅ | |
| Offline favorites / maps | ✅ | Cached stops & lines, offline map area |
| Dark mode, Hebrew/RTL, TalkBack | ✅ | |
| Service alerts from operators | ❌ | No free official feed (MOT feed needs a key) |
| Wheelchair-accessible stops/routes | ❌ | Not in the Stride API |
| Mobile ticketing / Rav-Kav payment | ❌ | Needs operator contracts |
| Crowd reports, user issue reports | ❌ | Needs a backend; BusLive has none (privacy) |
| AR way finder, AI chat assistant, bikes/scooters | ❌ | Out of scope / no data |
| Ads, account, tracking | 🚫 | BusLive has none, on purpose |
